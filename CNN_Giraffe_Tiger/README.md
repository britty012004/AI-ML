# CNN-Based Image Classification Using Streamlit

## Project Description
This project implements a Convolutional Neural Network (CNN) to classify images of Giraffes and Tigers.

## Technologies Used
- Python
- TensorFlow
- Streamlit
- NumPy
- Matplotlib

## Dataset
- Giraffe
- Tiger

## How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Train the model:
python train.py

3. Run the application:
streamlit run app.py
